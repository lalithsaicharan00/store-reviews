A LITTLE HELP

Keep going.
We are here to help.

Guidance for the app under development. Available features and menu names may vary by platform or build.

Getting started

Create a habit, choose its schedule and set a goal using checks, amounts, time or checklist steps. Weekly and monthly goals do not require the same amount every day.

Logging and routines

Use the habit’s check or amount control to log an action. Timers track duration; checklists track steps. Guided routines take you through habits one at a time. The named Undo action corrects the most recent entry.

Widgets and reminders

Add Often Enough from the system widget gallery, then use Edit Widget to choose a habit or section. Checks, saved increments and timers act directly on supported Home Screen widgets; actions needing more information open the app. Lock Screen families have different capabilities.

Use Privacy & Security → Hide Names Outside the App to hide names in widgets and reminders. Manage notification permission in device settings.

Backup and moving devices

Check the app’s iCloud & Backup page for cloud status. Use Save a Backup File before moving or deleting the app. Save outside Often Enough’s own folder. CSV export is for reading history; use a backup file for restoring.

Use Restore From a Backup or Import a Backup File on the destination device and review its preview. iCloud recovery requires the correct Apple Account and cloud settings. Storage, permissions and connectivity affect backup and sync. Google Drive and Android support are being prepared.

Plus and purchases

Start with five active habits. Plus is a one-time in-app purchase. Use Restore Purchases with the same store account if your purchase is missing. Refund requests go to the store. See Plus.

Account and data removal

The current Apple architecture has no separate Often Enough habit account. Device records, cloud copies and store purchases have separate controls. See data-removal instructions.

Still need a hand?

Write to support@oftenenough.com. Include your device, OS, app version and what happened. Send screenshots or habit details only if you choose to. We do not need your password or card details.
