## Decisions and progress

Research: [Today's Rows — Tap, Swipe, the Day Sheet and Delete](<../../../Research/Research Reports/Day Structure and Organization/Today's Rows — Tap, Swipe, the Day Sheet and Delete.md>)
(3 Oct 2026: 1,700 reviews read, 794 on topic). Rulebook U13 (updated) and U14 (new); Design Rules' new section
"A row's tap, swipes, menu and Day sheet".

| Point | Decision, and where it's built |
|---|---|
| R1 | Built as "stay in place" by default, then **reversed by the user the same day**: done habits move down (`DoneOrder.bottom`, the default again), Stay in Place in Appearance. See the next checklist's L1 |
| R2–R4 | A tap on a row (not the button) sets `store.dayTarget`: the Day sheet for the day Today shows. The sheet's day is the bottom bar's ‹ date ›, the same control as Today's bar; its title is "Yesterday · Water" when opened from yesterday |
| R5 | Sheet sections: who (icon, name, plan) and Result → the habit's control and Add Entry → that day's entries (editable) → Today/This Day (Skip, Note) → Habit (Open Habit Page, Edit Habit, Pause/Resume) |
| R6 | Delete is in the sheet's ⋯ menu with Archive; Delete asks first with "Archive Instead". Never on a swipe, never in the long-press menu, never a red button in view |
| R7 | Per type: Done switch (once a day, weekly day), Add 1 (several a day), +step (amounts with a step), Start Timer / Pause and save (time, today), steps (checklist), Log a Slip (quit); Add Entry for everything else |
| R8 | Swipe left: Note (full swipe), Skip/Undo Skip, Pause/Resume. Swipe right: the named Undo of the day's last entry, no full swipe |
| R9 | `Entry.undoLabel`: "Undo +1 glass", "Undo 20 min", "Undo +1", "Undo Done", "Undo Slip", "Undo <step>": on the inline Undo, the swipe and the menu |
| R10 | Long press: Open Habit Page (Today's stack), Edit Habit, Add Entry…, Note, Skip, Pause…, the named Undo, All Notes. "Edit Today's Progress…" and "Log amount/time manually" removed (the tap and Add Entry cover them) |
| R11 | `isTicked` (a weekly count's ✓ is that day's tick) and `countsUp` (a check several times a day is a +1 counter). ✓ toggles, + adds, everywhere on the row |
| R12 | Each mechanism is the iPhone's own: Reminders/Mail's circle-acts, row-opens; Mail/Reminders' trailing swipe buttons; a ⋯ menu for rare destructive actions; Health's tap-to-see-data |
| R13 | Tests: `TodayRowSheetUITests` (every kind opens the sheet; follows the day; actions and the ⋯ Delete; swipes; ✓ toggles / + adds; long press), `ProgressCheck` tap rule, updated Today/Undo/GoalFlow tests; speed: "Today: a row's Day sheet" in `tap-today` |
