# Creating a Habit — Round 3, The User's Own Words

Written by Claude (Claude Code), 28 September 2026, from the user's request of the same day. It follows [Schedule and Goal — Round 2](<Schedule and Goal — Round 2 Checklist.md>); the user rejected round 2's design as still rule-based.

**Context (the user's words, tidied):** the design must match how people think. Imagine a person whose job is to write down habits as someone says them: "I want to track reading, my weekly goal is two chapters". Whatever someone says, they write it straight down. The app must work like that: a person's literal words turn into the habit on screen. Right now everything is rules: Schedule vs weekly goal, hidden rules like "+ adds 1 here but opens a number screen there". Those complications come from not matching the user's mental model.
