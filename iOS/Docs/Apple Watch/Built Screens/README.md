# Apple Watch — Built Screens

Written by Claude (Claude Code), 11 October 2026 (Current Work 82).

The Watch app as built, photographed on GitHub's Watch simulators by `WatchScreenshotTests` (run
[38134016683](https://github.com/lalithsaicharan00/store-reviews/actions/runs/38134016683), the final code): every
screen in [Designs](<../Designs/Design Notes.md>) on the **46 mm** and **42 mm** Apple Watch Series 10, and the main
screens at a large accessibility text size (H20). Reduced to 128 colours to keep them small; the full-size pictures of
each run are on the `ci-results` branch (`watch/shots`).

Names follow the designs: A Today, B Day details, C the routine, E the watch face and Smart Stack, G Plus, H the states
added after the cross-check. Where version 1 differs from the pictures: [Design Notes, "As built"](<../Designs/Design Notes.md>).

The screenshot review (build prompt §6) went round five times; what each round fixed is in
[Current Work, item 82](<../../Checklists/Current Work Checklist.md>). Simulator pictures aren't the last word: look at
every screen on the real Watch too (U9).
