# Today Screen, Question 25: Section Times — Start, End and Adding Between

> **Written by Claude (Claude Code)**, 24 September 2026. Authorship of every report is listed in the [Research Reports index](<../../README.md>).

**Status: research, not a decision.** Decisions live in Notion. Round 3 follow-up 2. This report **revises Question 23's "Set a time" switch**.

**The feedback.**
- Anytime can't be deleted, so a "Set a time" switch makes no sense: every other section is timed.
- The first timed section needs both a start and an end.
- Later sections could need only a start.
- Adding a section before, between or inside existing ones needs rules.
- Is an end always needed?

**Basis.**
- **Reviews:**
  - a new whole-corpus screen for section start/end wording and overlaps found 4 matches, none about day sections;
  - the Day Structure report's 28 hand-read reviews on changing section times.
- **First principles:** the main basis, because reviews say little about the edge cases. Every rule below is marked **(reasoned)**.

---

## What a section's time is for (reasoned)

A habit is never locked to its section's window: a morning habit can still be ticked at night. So a section's time only does three things:
1. It puts the sections in order on Today.
2. It decides which section is marked **Now**, and where Today scrolls on open.
3. It decides what the **Afternoon** filter chip calls "now".

So times must never overlap, because two sections can't both be "now". Precision matters most at the point where a wrong answer would be visible: the **latest** section. Without an end, "Morning" would be marked Now all evening.

---

## The rules

1. **No "Set a time" switch.**
   - Anytime is the only untimed section. Every other section has a time.
   - Someone who wants an untimed "After work" puts those habits in Anytime.
2. **Every section has a start.**
3. **Only the latest section asks for an end.** Every other section ends when the next one starts, shown read-only: "Ends 12:00 · when Afternoon starts".
   - The first timed section is also the latest, so it **can't be saved without an end**.
   - An end must be after the start, and no later than **New day starts at**.
4. **Adding before the first** (04:00, when Morning starts at 06:00): its end fills in as 06:00. No end field is shown.
5. **Adding inside an existing section** (09:00 inside Morning 06:00–12:00): the new section takes the rest of that window.
   - Morning becomes 06:00–09:00 and the new one 09:00–12:00.
   - Before saving, one line shows the effect: "**Morning will end at 09:00**."
   - Carving out part of a window is what someone adding "Mid-morning at 09:00" means, so splitting matches their intent **(reasoned)**.
6. **Adding after the latest:**
   - If it starts inside the latest section's window, rule 5 applies, and the new section inherits that end (editable).
   - If it starts after the latest ends, it becomes the latest and asks for its own end. The previous latest now ends where the new one starts, and a line says so.
7. **Deleting** never leaves a hole between sections:
   - Deleting a middle section extends the one before it to the next start.
   - Deleting the latest leaves the one before it as the latest, keeping its own end.
   - Each change is shown before saving.
8. **Gaps can exist only after the latest section,** before the new day starts. Nothing is marked Now then, and habits are unaffected. **Overlaps can't happen**, because ends are derived.

---

## Key findings

**1. People think in starts.**
- The Day Structure reviews on retiming talk about when a part of the day *begins*: "my morning starts at 9", "at noon". None of those 28 reviews asks to set an overlap or a gap on purpose.
- So a start per section, with ends derived, fits how people describe their day.

**2. The edge cases have no review evidence, so they are reasoned.** The rules above follow three principles:
- **Never a hidden conflict:** no overlaps, so "Now" is always one section.
- **Show every side effect before saving:** "Morning will end at 09:00".
- **Ask only for what can't be inferred:** only the latest section's end.

**3. The only overlap reviews are about something else.**
- A timed-routine app, where extending one block made it overlap the next (`A17#30`).
- A wish to run two routines at once (`A5#94`).
- Neither applies to day sections, which are containers, not timers.
