# Q42 morning glance — codebook
WANT_ALL   wants/praises seeing all or several of today's habits at once
SCROLL_BAD complains about scrolling / too few per screen / cards too big
DENSE      wants compact rows / smaller items (incl. smaller done items)
MANYN      states they track many habits (number in note if given)
LEFT       wants to see what is left / find the undone ones quickly
COUNT      wants a number: how many today / how many left (badge, widget, header)
BADGE_UNCLEAR badge number shown but user can't tell what it refers to
HIDEDONE   wants done habits hidden, collapsed or moved out of the way
KEEPDONE   wants done habits to stay visible
NOWONLY    wants/praises seeing only what belongs to the current part of the day
ONEATATIME wants/praises a one-at-a-time / step-by-step view
NEXT       wants/praises a "next up" habit
OVERW      overwhelmed by seeing the whole list or a big number
HIDECOUNT  wants the total/left number hidden (overwhelm)
COLLAPSE   wants collapsible sections/groups
PLAN       uses the list to plan / preview the day in the morning
TIMELINE   praises/wants a time-ordered timeline of the day
GROUPING   uses groups/sections to cope with a long list
GLHIST     "at a glance" means history/progress (week, calendar, stats), not today's list
GLTODAY    "at a glance" praise about today's list/status
NOTDUE     wants only today's due habits shown (hide not-due)
SUMMARY    wants a short day summary (text/overview) rather than the full list
HIDDENLIST today's own list is hard to find among other content
RUNNER     praises a guided routine runner that tells you the next task / finish time (a separate job from the glance)
CALM       praises seeing only what's needed without being overwhelmed
ONE_BAD    dislikes a one-at-a-time view; wants to see the rest of the list
HIDEDONE_ISSUE hide-completed exists but misbehaves (hides before skip, weekly habits, widget mismatch)
FILTER     uses/wants a filter to narrow today's list
PRIORITY   wants chosen/important habits first or pinned, without scrolling
TRIM       wants to shrink today to a smaller set on a hard/busy day
NOWONLY_BAD dislikes being shown only the current part of the day / split lists
SECTIONS   praises time-of-day sections for making a long day manageable
PREVIEW    wants to preview upcoming days' habits
FORGET_BELOW habits below the fold get forgotten / missed
COLLAPSE_BAD dislikes content collapsed/folded by default
PLANGEN    generic praise "helps me plan my day" (no detail on what is shown)
