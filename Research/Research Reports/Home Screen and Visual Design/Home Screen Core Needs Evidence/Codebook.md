# Codebook — Home Screen Core Needs

Written by Claude (Claude Code), 21 November 2026. One review can carry several codes. "-" means nothing about the app's daily use.

## The need groups used in the report

| Group | Codes |
|---|---|
| 1 Hold it for me | REMEMBER, VERIFY |
| 1b Reach me outside the app | OUTSIDE |
| 2 See my day at a glance | WHOLE_DAY, WHATS_LEFT, PLAN, PREVIEW, PREVIEW_NEXT, NOW, FIND, FORGET_BELOW |
| 3 Not too much | OVERWHELM, ONE_THING, TRIM, DENSE, CALM, SIMPLE, DONE_AWAY |
| 4 Ticking feels good and shows I'm moving | QUICK, REWARD, PROGRESS, COUNT, DONE_KEEP |
| 5 Fits my life, my order | GROUPING, ORDER, PRIORITY, CONTROL, FIT, NOTDUE, MANY |
| 6 Kind when I slip | NO_GUILT, GUILT, BACKFILL, MISSED_EARLIER |
| 7 Can be trusted | CORRECT, SYNC |

## Codes

| Code | Meaning |
|---|---|
| REMEMBER | I forget; the app holds it and reminds me (meds, chores, "what I have to do") |
| VERIFY | Did I already do it? Can't tell done from not-logged |
| WHATS_LEFT | What's still to do today |
| WHOLE_DAY | See everything for the day in one place, at a glance |
| PLAN | Organise / plan my day |
| PREVIEW / PREVIEW_NEXT | See coming days / what's next |
| NOW | What to do right now |
| FIND | Can't find a habit, an action or a screen |
| FORGET_BELOW | Things below the fold or on another page get forgotten |
| OVERWHELM | A long list or a busy screen overwhelms |
| ONE_THING | One thing at a time; start small; guided step by step |
| ONE_THING_BAD | One-at-a-time hides the rest (complaint) |
| TRIM | Fewer items is better; a cap helps |
| DENSE | Too busy, too big, too much on screen |
| CALM | Calm, quiet, not loud |
| SIMPLE | Simple, clean, easy (praise or wish) |
| DONE_AWAY | Done items should leave, sink or hide |
| DONE_KEEP | Done items should stay visible (proof of effort) |
| QUICK | Ticking must be fast and on the main screen |
| REWARD | Ticking off feels good; sound, celebration, pet |
| PROGRESS | See how I'm doing (percent, streak, chart) |
| COUNT | Counts and amounts (5/7, glasses, days since) |
| OUTSIDE | Widget, watch, lock screen, notification action, badge |
| GROUPING | Morning/evening, categories, lists, folders |
| ORDER / PRIORITY | My own order; important things on top |
| CONTROL | Schedule and setting options (x per week, invert, rename) |
| FIT | Fits my real day (shift work, day end, vacation, flexible ranges) |
| NOTDUE | Show only what's due; don't count not-due days |
| MANY | Many habits / more pages |
| NO_GUILT / GUILT | Kind, not punishing / guilt or pressure (some like a little) |
| BACKFILL | Log or fix earlier days |
| MISSED_EARLIER | Undone items carried to the next day |
| CORRECT | Bugs: reminders that don't fire, lost ticks, wrong day, crashes |
| PLAN | Organise my day |
| Set B only | PAY (price, ads, upsell), SCAM (charged unexpectedly), LIMIT (free cap), MENTAL (mental health), SOCIAL, SYNC (devices, backup, lost data), CUSTOM (looks, sounds), GENERIC (praise with no content), EXPORT, PRIVACY, LANG, ACCOUNT |
