# Codebook — new and returning people at first launch (Current Work 73 + 3, 9 Oct 2026)

One line per review in cls/NN.txt: `idx CODE CODE … | optional exact quote fragment`.

| Code | Meaning |
|---|---|
| NR | Not about getting back in, first launch, or the account |
| LOST_NOWAY | Reinstalled / new phone / reset: data gone, no way offered to get it back |
| SIGNIN_EMPTY | Signed in on return: "no account", not recognised, or signed in and nothing came back |
| LOGIN_FRICTION | Signing back in blocked: codes, links, passwords, keys, errors, logged out |
| NO_LOGIN_ENTRY | Couldn't find where to log in / sign in (at the start or anywhere) |
| MOVE_UNCLEAR | Didn't know how to move to a new phone or get the old data on this one |
| NEVER_KNEW | Only learned after a loss that an account or backup was needed |
| MANUAL_TRAP | The backup only existed if made by hand; expected automatic |
| RESTORE_FAIL | A restore / sync-down / backup file failed, was empty, or brought back only part |
| RESTORE_OK | Signing in or restoring brought everything back (praise) |
| ICLOUD_FAIL | iCloud backup / sync didn't bring data back on a new phone or reinstall |
| ICLOUD_OK | iCloud brought it back, or "no login, iCloud" praised |
| PURCHASE_LOST | Paid access not restored on reinstall / new phone, or restore-purchase hard |
| PURCHASE_OK | Paid access came back on reinstall / new phone (praise) |
| NEW_START | Had to start over / make a new account |
| ONBOARD_AGAIN | A returning person made to go through intro / questions / setup again |
| NOACC_PRAISE | Praise for no account / no login needed |
| FORCED_ACCOUNT | Forced to make an account / log in before using |
| ACCOUNT_FIND | Can't find account settings, sign-out, or which account they're in |
| WRONG_DOOR | Signed in with a different method / email → empty or new account; sign-up vs log-in confusion |
| ASKED_RESTORE | The app asked or offered to restore at the start (note outcome) |
| AUTO_FOUND | The app found the account / backup by itself, or "everything was just there" |
| EXPECT_SIGNIN | States the expectation: just sign in and pick up where they left off |
| SUPPORT | Needed support to get back in (or couldn't reach it) |
| FIRST_RUN_BAD | New-user first run: confusing, long, interrupting |
| FIRST_RUN_GOOD | New-user first run praised as easy / quick |
