# Q44 codebook
GRID_WANT     wants a grid / tiles / more per row to fit more habits on one screen
LIST_WANT     wants a list view back from circles or tiles
CIRCLE_PRAISE praises a circle/bubble layout
TINY_TAP      small targets in a row are hard to tap
STREAK_MAIN   wants the streak on the main screen (complains when removed)
TRUNC         names/text cut off or truncated (often with larger text)
