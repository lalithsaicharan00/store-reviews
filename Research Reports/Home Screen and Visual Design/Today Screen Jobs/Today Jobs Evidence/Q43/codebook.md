# Q43/Q44 codebook
UNTIMED     has / wants / praises habits with no set time of day ("any time", "whenever", x-per-week)
HIDDEN_BAD  an untimed/all-day list was hidden or not shown with the current part; complaint
SEE_ALWAYS  wants untimed habits visible all the time, on the same page as the time parts
NOWFOCUS_OK praises seeing only the current part of the day
FORCED_BAD  dislikes being forced to give every habit a time
WANT_TIME   wants to set times / time parts (so untimed is not the only option)
QN          states how many quit counters / trackers they keep (number in note)
QSEE        wants the quit counter visible at a glance (home, widget, first screen)
QMANY_PROB  many counters become hard to see / need organising
